# Noorverse Portfolio

A modern personal portfolio website built to showcase projects, experience, skills, and contact details in a polished, interactive format.

## Overview

This project is a personal portfolio for Noorverse, featuring:

- Animated hero section
- About and experience sections
- Skills and services highlights
- Project showcase cards
- Journey timeline
- Contact form section
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts

## Features

- Modern glassmorphism-inspired UI
- Smooth scrolling and interactive animations
- Responsive layout
- Project cards with hover details
- Contact section with a form UI
- Minimal, premium branding

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/mahanoornaeem2290/New-Portfolio.git
```

2. Open the project folder:

```bash
cd New-Portfolio
```

3. Open `index.html` in your browser.

You can also use a local development server if preferred.

## Customization

To personalize the portfolio:

- Update text in `index.html`
- Modify colors, spacing, and layout in `style.css`
- Adjust animations and interactions in `script.js`
- Replace the profile image in `assets/mahanoor-photo.jpg`
- Replace the resume file in `assets/Mahanoor_Naeem_CV.pdf`
